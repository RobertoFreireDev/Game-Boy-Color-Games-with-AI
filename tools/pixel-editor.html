Rules checked: sprite sheets use ≤ 3 visible colors per 8×8 tile from one of 8 palettes (color 0 = transparent). Map sheets use ≤ 4 colors per 8×8 tile from one of BG palettes 0–6, no transparency, ≤ 128 unique tiles (mirrored copies count once). All colors are RGB555, so every exported color survives RGB8() exactly. Work is autosaved in this browser.
